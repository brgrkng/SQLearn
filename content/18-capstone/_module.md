---
title: "Capstone: a city bike-share"
summary: One realistic system end to end. Design the schema from a brief, load messy data, answer the business's questions, and tune the slow query.
---
Everything comes together here. You'll work through the same system the way you would on the job: start from a written brief, design and constrain the schema, load data from a messy export, answer questions from the operations team, and fix a slow dashboard query.

The query parts run against **bikeshare**, a dataset matching the reference design: 40 stations, 600 bikes, 3,000 members and about 60,000 trips (April to September 2025).
