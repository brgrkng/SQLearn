---
title: "Beyond relational: PostgreSQL power features"
summary: JSONB documents, arrays, range types and full-text search. When to use them, how to query them, and how to index them.
---
PostgreSQL is relational at heart, but it also stores and indexes **semi-structured** data: JSON documents, arrays, ranges of values, and searchable text. These features remove the need for a second database for many workloads.

Use them where they fit the data. Structured, constrained facts still belong in proper columns and tables.
