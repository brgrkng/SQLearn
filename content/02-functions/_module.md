---
title: Functions and expressions
summary: Text, numbers, dates and times, CASE and type casts. The tools for computing new values from the columns you have.
---
Raw columns are rarely exactly what you need. You trim and split text, round money, find out how many days an order took to ship, or turn a status code into a label. This module covers PostgreSQL's built-in functions for text, numbers and dates, the `CASE` expression, and type conversion.

You'll use three datasets: **shop**, **hr** (a 300-person company) and **analytics** (a web app's event stream with real timestamps).
